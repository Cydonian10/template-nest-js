# Requisitos no funcionales

## RNF-001 Seguridad

- Las contraseñas deben almacenarse utilizando un algoritmo de hash seguro.

## RNF-003 Autorización

- Los endpoints protegidos deben verificar los permisos del usuario.

## RNF-004 Auditoría

Las operaciones críticas deben registrar:

- usuario
- fecha
